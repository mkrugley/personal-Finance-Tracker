# Personal Finance Tracker

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Python](https://img.shields.io/badge/python-3.6+-blue.svg)
![CI](https://github.com/flexxrap/personal-Finance-Tracker/actions/workflows/ci.yml/badge.svg)

Простое консольное приложение для отслеживания личных финансов на Python.

## Возможности

- Добавление доходов и расходов
- Гибкие категории (пользователь может создавать свои категории)
- Просмотр текущего баланса
- Просмотр всех транзакций
- Статистика по категориям
- Расширенная статистика (общая сумма, средние значения, лучшие/худшие месяцы и т.д.)
- Удаление транзакций
- Экспорт данных в CSV

## Установка

1. Убедитесь, что у вас установлен Python 3.6 или выше
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Использование

Запустите приложение:
```
python main.py
```

Следуйте инструкциям в меню:
1. Добавить доход
2. Добавить расход
3. Показать баланс
4. Показать все транзакции
5. Статистика по категориям
6. Расширенная статистика
7. Удалить транзакцию
8. Экспорт в CSV
0. Выход

## Тестирование

Проект включает unit-тесты для основной функциональности:

```
python -m unittest discover tests
```

## Структура проекта

- `main.py` - основной файл приложения
- `tests/` - unit-тесты
- `requirements.txt` - зависимости проекта
- `.github/workflows/` - GitHub Actions workflows
